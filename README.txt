PROJET : LE pH DES SODAS
========================

Fichiers :
- index.html : structure et contenu du site
- style.css  : apparence, couleurs et mise en page
- script.js  : tableau interactif, graphique et sauvegarde de la conclusion

LANCER LE SITE
1. Décompresse le ZIP dans un dossier.
2. Ouvre le dossier dans Visual Studio Code.
3. Ouvre index.html dans un navigateur (double-clic suffit).
   Option pratique : installer l’extension "Live Server" dans VS Code,
   puis clic droit sur index.html > Open with Live Server.

PERSONNALISER
- Texte et sections : index.html
- Couleurs et design : style.css (variables en haut du fichier)
- Valeurs d’exemple : script.js, tableau initialRows au début du fichier

IMPORTANT POUR TON PROJET SCIENTIFIQUE
Les valeurs de pH sont des exemples fictifs pour montrer le fonctionnement du site.
Remplace-les par tes propres mesures et indique le matériel, les conditions et les limites.
La conclusion peut être enregistrée localement dans le navigateur utilisé.
